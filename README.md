# ⚡ ربات سرخط‌زن — سیگنال شکست با درجه اعتبارسنجی

<div dir="rtl">

سیگنال‌گیر **شکست محدوده ابتدای جلسه** برای **بورس تهران (TSETMC)** و **کریپتو (نوبیتکس)** —
با **دیتای واقعی**، **امتیاز اعتبارسنجی ۸ فاکتوری (۰ تا ۱۰۰)**، اپلیکیشن موبایل قابل نصب و
**بدون حتی یک کتابخانه اضافه** (فقط پایتون خام).

> ⚠️ **سلب مسئولیت**: این نرم‌افزار فقط سیگنال و معامله شبیه‌سازی (پیپرتریدینگ) ارائه می‌دهد.
> معامله واقعی به‌صورت پیش‌فرض قفل است و مسئولیت هر تصمیم مالی با خودِ شماست.

## 🚀 شروع سریع — سه راه

### راه ۱) نصب روی گوشی اندروید (پیشنهادی — بدون کامپیوتر)

<div dir="ltr">

```bash
# ۱) برنامه Termux را از F-Droid نصب کن: https://f-droid.org/packages/com.termux/
# ۲) داخل Termux بزن:
pkg update -y && pkg install python -y
cd ~
# پوشه ربات را داخل Termux کپی کن (دانلود zip از GitHub → استخراج → جابه‌جایی)
cd sarkhat-bot
python main.py serve
```

</div>

بعد **اپ اندروید** را نصب کن (APK آماده از تب Actions مخزن GitHub — پایین همین صفحه) —
اپ به‌صورت پیش‌فرض به `http://localhost:8000` وصل می‌شود، یعنی به ربات داخل همین گوشی.

### راه ۲) روی کامپیوتر (ویندوز/لینوکس/مک)

<div dir="ltr">

```bash
cd sarkhat-bot
python main.py serve            # سرور + اپلیکیشن
# مرورگر: http://localhost:8000
```

</div>

### راه ۳) بدون نصب — وب‌اپ

اگر مالک مخزن هستی و workflow «Pages» فعال باشد:
`https://<نام‌کاربری>.github.io/<نام‌مخزن>/` را در کروم اندروید باز کن و
«Add to Home Screen» بزن. سپس در تب تنظیمات، آدرس سرور ربات را بده.

## 📱 گرفتن APK اندروید

هیچ‌چیز لازم نیست کامپایل کنی! GitHub خودش می‌سازد:

1. این پروژه را به GitHub خودت push کن (راهنما: `docs/GITHUB-SETUP.md`)
2. تب **Actions** → ران «ساخت APK اندروید» → بخش **Artifacts** → `SarkhatBot-APK`
3. فایل zip را باز کن و `app-debug.apk` را روی گوشی نصب کن
   (اجازه «نصب از منابع ناشناس» را بده)

## 🧠 درجه اعتبارسنجی سیگنال‌ها

هر سیگنال از ۸ فیلتر مستقل عبور می‌کند و امتیاز ۰ تا ۱۰۰ می‌گیرد:

| فاکتور | حداکثر امتیاز |
|---|---|
| شکست واقعی محدوده ابتدای جلسه | ۲۰ |
| تأیید حجم (۲.۲ برابر میانگین) | ۲۰ |
| روند روزانه (میانگین ۲۰/۵۰ روزه) | ۱۵ |
| RSI — نه اشباع خرید | ۱۰ |
| کیفیت کندل شکست (بسته‌شدن نزدیک سقف) | ۱۰ |
| نقدشوندگی (ارزش روزانه) | ۱۰ |
| هم‌جهتی با شاخص کل / بیت‌کوین | ۱۰ |
| نسبت سود به ریسک | ۵ |

**درجه‌ها:** `A ≥ 80` عالی • `B ≥ 65` خوب • `C ≥ 50` ضعیف • زیر ۵۰ = رد

علاوه بر امتیاز، **فیلترهای سخت** هم هست (حجم زیر ۱.۳ برابر، RSI بالای ۸۰، اسپرد باز) —
اگر رد شوند، اصلاً سیگنال حساب نمی‌آیند.

## 🛡 مدیریت ریسک (غیرقابل مذاکره)

- حداکثر **۱٪** ریسک در هر معامله
- توقف روزانه با **۲٪** ضرر
- حداکثر **۳ معامله در روز**
- حداکثر **۲۵٪** درگیری سرمایه

## 💰 مقرون‌به‌صرفه برای همه

- صفر وابستگی: هسته ربات فقط با کتابخانه استاندارد پایتون (حتی pandas نمی‌خواهد)
- APK حدود ۲ مگابایت — گوشی ضعیف و قدیمی (اندروید ۵ به بالا) راحت اجرا می‌کند
- حالت کم‌مصرف: کش طولانی‌تر، اسکن کمتر، بدون فونت و تصویر سنگین
- کاملاً رایگان و متن‌باز

## 🗂 ساختار پروژه

```
sarkhat-bot/
├── main.py                 ← نقطه ورود: backtest | paper | serve | live
├── config.py               ← همه تنظیمات (سرمایه، ریسک، نمادها، کلیدها)
├── core/
│   ├── market_data.py      ← دیتای واقعی TSETMC + Nobitex (پایتون خالص)
│   ├── signal_engine.py    ← موتور امتیازدهی ۸ فاکتوری + درجه A/B/C
│   ├── strategy.py         ← استراتژی شکست محدوده
│   ├── risk_manager.py     ← قوانین ریسک
│   ├── paper_broker.py     ← بروکر شبیه‌سازی (لغزش + کارمزد)
│   ├── nobitex_broker.py   ← قالب سفارش واقعی کریپتو (فقط با کلید API)
│   └── tse_broker.py       ← قالب سفارش واقعی بورس (API کارگزاری)
├── server/app.py           ← سرور سبک + API + اسکنر پس‌زمینه
├── webapp/                 ← اپلیکیشن موبایل (PWA فارسی RTL)
├── mobile/                 ← پروژه اندروید (WebView) — با Actions به APK تبدیل می‌شود
├── backtest/               ← بک‌تست روی داده تاریخی
└── .github/workflows/      ← ساخت خودکار APK + انتشار Pages
```

## 🔌 اندپوینت‌های API (برای توسعه‌دهندگان)

| مسیر | کار |
|---|---|
| `GET /api/health` | وضعیت سرور، اتصال منابع، تنظیمات |
| `GET /api/signals` | آخرین سیگنال‌ها با چک‌لیست اعتبارسنجی |
| `GET /api/market` | قیمت لحظه‌ای نمادها |
| `GET /api/trades` | گزارش پیپرتریدینگ + وضعیت ریسک |
| `GET/POST /api/settings` | تنظیمات (درجه حداقلی، اسکن، نمادها) |
| `POST /api/scan` | اسکن فوری |

## ❓ پرسش‌های رایج

**چرا می‌گوید «حالت نمایشی»؟**
سرورهای TSETMC و نوبیتکس فقط از IP ایران پاسخ می‌دهند. ربات را داخل ایران اجرا کن تا
دیتای واقعی وصل شود. بیرون ایران، ربات برای دیدن رفتار برنامه، داده نمایشی می‌سازد
(با برچسب واضح) و می‌توانی با `SARKHAT_ALLOW_DEMO=0` کلاً خاموشش کنی.

**ساعت کار بورس؟** شنبه تا چهارشنبه ۹:۰۰ تا ۱۲:۴۵ به وقت تهران. کریپتو ۲۴ ساعته است.

**معامله واقعی؟** قفل است. `config.py` را ببین (`ENABLE_LIVE`). اول حداقل یک ماه
`backtest` و `paper` را اجرا کن.
