# ربات ابری سرخط‌زن — بدون کامپیوتر! ☁️

از این نسخه، ربات **روی سرور رایگان گیت‌هاب (GitHub Actions)** اجرا می‌شود.
یعنی هیچ‌وقت نیاز نیست کامپیوتر روشن کنی یا Termux را باز نگه داری.

## چطور کار می‌کند؟

```
GitHub Actions (هر ۵ دقیقه)          اپ روی گوشی شما
┌────────────────────────────┐       ┌──────────────────────┐
│ Watcher → گرفتن دیتای واقعی │       │  سیگنال‌های بورس      │
│ Brain   → پیش‌بینی و امتیاز │  ───► │  بیت‌کوین ۵ دقیقه‌ای   │
│ Executor→ شرط شبیه‌سازی     │ دیتا  │  معاملات شبیه‌سازی    │
│ Guard   → کنترل ریسک       │  JSON │  تنظیمات و تلگرام    │
└────────────────────────────┘       └──────────────────────┘
        data/live.json  ◄──── همیشه آخرین وضعیت
```

- **بورس تهران:** همان موتور ۸ فاکتوری قبلی — در ساعات بازار (۹ تا ۱۲:۴۵، شنبه تا چهارشنبه) هر ۵ دقیقه اسکن می‌شود.
- **بیت‌کوین ۵ دقیقه‌ای:** مثل ربات‌های بازار دوتایی (نمونه Polymarket) — پیش‌بینی جهت ۵ دقیقه بعدی با امتیاز اعتماد ۰ تا ۱۰۰.
  منبع دیتا: نوبیتکس (داخل ایران) و اگر نبود Coinbase / CoinGecko.
- **همه‌چیز شبیه‌سازی (پیپر) است** — هیچ پول واقعی درگیر نیست.

## اپ اندروید — نسخه ۲.۱

APK جدید را دانلود و نصب کن (روی نسخه قبلی نصب می‌شود):
- آدرس پیش‌فرض اپ حالا **سایت ابری** است — یعنی همان خطای «سرور پیدا نشد» دیگر نمی‌بینی.
- تب جدید **بیت‌کوین**: جهت ۵ دقیقه بعدی + اعتماد + شمارش معکوس پنجره + شرط خودکار شبیه‌سازی.
- اگر روزی خواستی به سرور محلی (Termux) وصل شوی: منوی سه‌نقطه → «تغییر آدرس».

## اعلان تلگرام (اختیاری)

دو راه داری:

**راه ۱ — از داخل اپ (ساده‌تر):**
1. در تلگرام به `@BotFather` پیام بده → `/newbot` → یک اسم بگذار → توکن را کپی کن.
2. به `@userinfobot` پیام بده → chat_id خودت را کپی کن.
3. در اپ: تب تنظیمات → «اعلان تلگرام» → توکن و chat_id را بگذار → «ارسال پیام تست».

**راه ۲ — در خود گیت‌هاب (اگر اپ بسته باشد هم پیام می‌آید):**
1. در صفحه مخزن: Settings → Secrets and variables → Actions → New repository secret
2. دو سکرت بساز: `TG_BOT_TOKEN` و `TG_CHAT_ID`
از این لحظه ربات ابری هم روی سیگنال‌های معتبر پیام می‌دهد.

## ورک‌فلوها (همه خودکار)

| فایل | کار |
|---|---|
| `brain.yml` | هر ۵ دقیقه مغز ابری را اجرا می‌کند و دیتای زنده را منتشر می‌کند |
| `pages.yml` | با هر تغییر اپ، سایت را به‌روز می‌کند |
| `android.yml` | APK می‌سازد و مستقیم روی سایت می‌گذارد |

## اجرای مغز ابری به‌صورت دستی (اختیاری، مثلاً در Termux)

```bash
python cloud/brain.py --data-dir webapp/data
# یا با میان‌بر:
python main.py brain
```

## نکته امنیتی

توکن گیت‌هابی که به دستیار داده‌ای، بعد از راه‌اندازی می‌توانی حذف کنی
(Settings → Developer settings → Personal access tokens → Delete).
ربات ابری با توکن داخلی خودش کار می‌کند و به توکن تو دیگر نیاز ندارد.
