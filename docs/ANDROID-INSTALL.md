# 🤖 نصب اپ اندروید سرخط‌زن (APK)

<div dir="rtl">

## روش ۱: دانلود APK آماده از GitHub (پیشنهادی)

1. به مخزن پروژه در GitHub برو → تب **Actions**
2. ران اخیر «ساخت APK اندروید» را باز کن (باید تیک سبز ✓ داشته باشد)
3. پایین صفحه در بخش **Artifacts** روی **SarkhatBot-APK** کلیک کن
4. zip دانلود شده را باز کن → `app-debug.apk`
5. فایل را به گوشی بده و نصب کن — اندروید می‌پرسد «نصب از منابع ناشناس؟»
   → اجازه بده (فایل از کد خودت ساخته شده، امن است)

> اولین بار که Actions اجرا می‌شود چند دقیقه طول می‌کشد. اگر Artifacts خالی است،
> چند دقیقه صبر کن و صفحه را رفرش کن.

## روش ۲: ساخت APK روی خودت (اختیاری)

اگر Android Studio داری: پوشه `mobile` را باز کن → `Build → Build APK`.
یا بدون Studio فقط با JDK 17 و گریدل:

```bash
gradle -p mobile assembleDebug
# خروجی: mobile/app/build/outputs/apk/debug/app-debug.apk
```

## قدم اول بعد از نصب

1. اپ «سرخط‌زن» را باز کن
2. دفعه اول ازت می‌پرسد **سرور ربات کجاست**:
   - ربات روی همین گوشی (Termux): `http://localhost:8000` بماند
   - ربات روی کامپیوتر: مثل `http://192.168.1.5:8000` (IP همان دستگاه در وای‌فای خانه)
3. اگر بعداً خواستی عوض کنی: منوی **سه‌نقطه** بالای اپ → «تغییر آدرس سرور»

## پیام «سرور پیدا نشد» دیدی؟

یعنی ربات هنوز روشن نیست. چک کن:

- Termux باز است و `python main.py serve` در حال اجراست؟
- اگر سرور روی کامپیوتر است: کامپیوتر و گوشی در یک وای‌فای باشند،
  و فایروال پورت ۸۰۰۰ را نبسته باشد
- آدرس را بدون تایپ اشتباه بده (با `http://` اولش)

## سوالات

**آپ چند مگابایت است؟** حدود ۲ مگابایت — از سبک‌ترین اپ‌های ترید دنیا.

**روی گوشی قدیمی جواب می‌دهد؟** هر اندروید ۵ به بالا (از سال ۲۰۱۴ به بعد).

**آپ پول من را معامله می‌کند؟** هرگز. اپ فقط سیگنال و پیپرتریدینگ نشان می‌دهد.
سفارش واقعی فقط از طریق قفل‌شدهٔ `live` و با کلید API خودت ممکن است.
