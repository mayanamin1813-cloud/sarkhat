# 📱 نصب ربات روی گوشی با Termux (بدون کامپیوتر)

<div dir="rtl">

Termux یک ترمینال رایگان لینوکس برای اندروید است — ربات مستقیماً روی گوشی خودت اجرا می‌شود
و به هیچ کامپیوتر و سروری نیاز نداری.

## قدم ۱: نصب Termux

- از **F-Droid** نصب کن (نسخه Play Store قدیمی است):
  https://f-droid.org/packages/com.termux/
- حجم حدود ۲۰ مگابایت

## قدم ۲: نصب پایتون

Termux را باز کن و تایپ کن (سطر به سطر):

```bash
pkg update -y
pkg install python -y
```

## قدم ۳: کپی کردن ربات

1. از مخزن GitHub فایل **ZIP** را دانلود کن (دکمه سبز Code → Download ZIP)
2. با فایل‌منیجر گوشی، zip را استخراج کن
3. پوشه `sarkhat-bot` را به مسیر اصلی Termux ببر:

```bash
# اگر استخراج در Downloads بوده:
cp -r /sdcard/Download/sarkhat-bot-main ~/
cd ~/sarkhat-bot-main
```

## قدم ۴: اجرای ربات

```bash
python main.py serve
```

می‌بینی:

```
🤖 ربات سرخط‌زن — سرور و اپلیکیشن موبایل
📱 اپلیکیشن: http://localhost:8000/
```

## قدم ۵: باز کردن اپ

- **راه ساده:** کروم را باز کن → `http://localhost:8000` → منوی سه‌نقطه →
  **Add to Home Screen** — حالا مثل یک اپ واقعی آیکون دارد!
- **راه حرفه‌ای:** APK اندروید را نصب کن (راهنمای `ANDROID-INSTALL.md`)

## ⏳ اجرای دائمی در پس‌زمینه

Termux وقتی بسته شود ربات هم می‌ایستد. برای دوام بیشتر:

```bash
pkg install termux-services -y
# یا ساده‌تر: اعلان Termux در نوار وضعیت را بکش و «Acquire wakelock» بزن
```

## 🔋 نکات مصرف

- حالت کم‌مصرف در تب تنظیمات اپ را روشن نگه دار (اسکن هر ۹۰ ثانیه)
- ربات فقط چند کیلوبایت در هر اسکن دیتا می‌گیرد — اینترنت کم مصرف می‌شود
- باتری تقریباً قابل چشم‌پوشی است چون محاسبات سبک است

## ⚠️ یادت باشد

- هر دو برنامه Termux و اپ باید **همزمان** باز/در پس‌زمینه باشند
- داخل ایران هستی؟ دیتای واقعی وصل می‌شود. بیرون ایران؟ حالت نمایشی می‌بینی
- برای خروج: در Termux دکمه Volume پایین + C را نگه دار
